Yeshiva Shorts Uploader

A personal command-line tool for publishing short-form Torah lesson clips to YouTube.

Privacy Policy Terms of Service

What this application does

Yeshiva Shorts Uploader is a single-user command-line program, run locally on the operator's own computer. It takes vertical video clips that were already rendered offline from recorded Torah lessons — each with its own title, description and tags — and uploads them to one YouTube channel that the operator owns or is authorized to manage.

The application exists to remove repetitive manual work. Everything it uploads was produced deliberately by a human beforehand; the tool only handles the transfer.

Who uses it

One person. It is not distributed, sold, or offered as a service, and it has no user accounts, no website interface, and no server component. There is no sign-up, because there is nobody to sign up.

How it uses Google APIs

The application uses the YouTube Data API v3 and requests exactly one OAuth scope:

  • https://www.googleapis.com/auth/youtube.upload — permission to upload a video file to the authorized channel.

This scope allows uploading only. The application does not read the channel's analytics, does not read or write comments, does not manage subscriptions, and does not modify or delete existing videos. Uploaded videos are created with private visibility; publishing them is a separate, manual decision made afterwards in YouTube Studio.

Revoking access. Authorization can be withdrawn at any time from Google Account → Third-party apps & services, which immediately and permanently ends the application's ability to upload. Deleting the local credentials file has the same practical effect on this machine.
