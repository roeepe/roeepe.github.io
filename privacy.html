Summary

Yeshiva Shorts Uploader is a single-user command-line program that runs on its operator's own computer. It collects no personal information from anyone, has no server, no database, and no analytics. The only credential it handles is the operator's own Google authorization token, which never leaves the machine it was created on.

What data the application accesses

When authorization is granted, Google issues the application an access token and a refresh token scoped to a single permission: https://www.googleapis.com/auth/youtube.upload. Alongside those tokens, Google returns the email address of the account that granted authorization, so the application can display which account is connected.

The application does not request and cannot obtain:

  • Channel analytics, watch history, or viewer data
  • Comments, messages, or subscriber lists
  • The ability to read, modify, or delete videos already on the channel
  • Contacts, Drive files, calendar data, or any other Google service

Where data is stored

Tokens are written to a single file on the operator's local disk (.youtube_token.json) and are read from there on each run. The video files being uploaded are likewise local files, chosen explicitly by the operator.

No data is transmitted anywhere except directly to Google's own API endpoints in order to perform the upload the operator requested. There is no third-party analytics, no telemetry, no error-reporting service, and no advertising network involved at any point.

How data is used

The token is used for one purpose: authenticating upload requests to the YouTube Data API on behalf of the account that granted it. It is never used for any other purpose, never shared with any third party, and never sold. The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The token file persists locally until it is deleted or the authorization is revoked. Because there is no server, there is nothing to delete remotely and no backup copy held anywhere.

To revoke access, either or both of:

  • Visit Google Account → Third-party apps & services, select this application, and choose Remove access. The stored token stops working immediately.
  • Delete the local .youtube_token.json file, which removes the credential from the machine.

Children

The application is a personal developer tool with a single adult operator. It is not directed to children and collects no information from anyone.

Changes to this policy

If the application's behaviour changes in a way that affects this policy — for example if it ever requested an additional OAuth scope — this page will be updated and the effective date above revised.
